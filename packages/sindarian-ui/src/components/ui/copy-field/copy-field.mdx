# CopyField

Displays a read-only value alongside a copy button. Built for values the user must transfer somewhere else — a
TOTP manual-entry secret, a recovery code, an API key.

Requires a `Toaster` mounted in the tree: copying raises a toast to confirm the action.

### Default

<Canvas of={Story.Default} />

### With label

The `label` is rendered above the field and associated with the input via `htmlFor`/`id`. Without it, the input
falls back to the `valueLabel` accessible name.

<Canvas of={Story.WithLabel} />

### Masked

Set `masked` to obscure the displayed value behind native password dots and offer a reveal toggle. Copy always
uses the raw `value`, even while masked.

<Canvas of={Story.Masked} />

### Auto-clearing the clipboard

Pass `clearClipboardAfter` (milliseconds) so a sensitive value doesn't linger in the clipboard. The clear runs
only after a confirmed clipboard write, and it reads the clipboard back first — if it no longer holds exactly
what this field wrote, nothing is touched, so a copy the user made in the meantime is never destroyed.

Best-effort by design: browsers without `navigator.clipboard.readText` (Firefox, Safari) or that deny the read
can't be verified, so the clipboard is left alone there. Treat it as defence in depth, not a guarantee. The
pending clear survives unmount, so closing the dialog early still wipes the value.

<Canvas of={Story.AutoClearingClipboard} />

### Custom toast label

Pass `onCopyLabel` with an i18n string to replace the default success message.

<Canvas of={Story.WithCustomToastLabel} />

### Clipboard fallback

When `navigator.clipboard` is unavailable or the write is rejected, the field reveals and selects its text and
raises a toast prompting the user to copy manually with `Ctrl`/`Cmd`+`C`. Pass `fallbackLabel` to localize that
toast.

### Monospace values

Set `mono` to render the value in the monospace face. Reach for it on identifiers, tokens and recovery codes,
where telling `0` from `O` decides whether the value the user reads back is the value. Everything else stays in
the app sans face, matching every other input.

### Description

Pass `description` for a one-line hint under the field — where the value belongs, how long it is valid. The
input points at it with `aria-describedby`, so a screen reader announces the hint with the field.

<Canvas of={Story.Localized} />

### Localization

Every user-visible string is overridable and defaults to English, so an existing consumer renders unchanged.

| Prop | Default |
| --- | --- |
| `copyLabel` | `Copy <label>`, or `Copy value` without a label (accessible name of the copy button) |
| `fallbackLabel` | `Copy not available — text selected, press Ctrl/Cmd+C` (fallback toast title) |
| `onCopyLabel` | `Copied to clipboard!` (success toast title) |
| `revealLabel` / `hideLabel` | `Show value` / `Hide value` (accessible name of the reveal toggle) |
| `valueLabel` | `Value to copy` (accessible name of the input when there is no visible `label`) |

The two remaining props carry no text: `mono` (`false`) selects the face, `description` renders nothing when
omitted.
