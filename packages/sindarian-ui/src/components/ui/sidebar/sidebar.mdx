# Sidebar

The main application sidebar, it features automatically active items by path, disabled states and collapsible behaviour.

Below 768px it can become an overlay drawer instead of a rail, opt-in through `mobile="drawer"` on `SidebarRoot` and opened by `SidebarTrigger`. The default, `mobile="inline"`, renders the rail at every viewport.
