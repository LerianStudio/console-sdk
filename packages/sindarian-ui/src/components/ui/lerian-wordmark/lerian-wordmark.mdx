# LerianWordmark

The Lerian wordmark from the brand kit, painted in `currentColor`. Size it by height through `className`; the width follows the mark's proportions. Pages without React use `dist/public/wordmark.svg` inline or as a CSS `mask` over `background: currentColor`; through `<img>` it always paints black.
