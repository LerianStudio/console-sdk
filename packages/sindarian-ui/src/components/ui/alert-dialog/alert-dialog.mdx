# AlertDialog

A modal that interrupts the user with important content and expects a response. \
[Docs](https://www.radix-ui.com/primitives/docs/components/alert-dialog)

Unlike `Dialog`, it cannot be dismissed by clicking outside — the user must pick
an explicit action. Use it for destructive or irreversible operations. For the
opinionated, ready-made confirmation flow, prefer `ConfirmationDialog`.
