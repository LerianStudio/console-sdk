# TextareaField

A multi-line text field wired to react-hook-form, for free-form input.

`required` drives the label asterisk and `aria-required`, not the native
`required` attribute — the resolver owns validation, same as `InputField`. For
a single-line control use `InputField`; for one that grows with its content,
`InputField` with `textArea`.
