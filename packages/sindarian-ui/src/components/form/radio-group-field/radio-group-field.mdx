# RadioGroupField

A single-choice field wired to react-hook-form. Pass the choices as `options`;
each entry renders a radio plus its own `Label`, so nothing else has to be
wired.

`disabled` on the field disables every option; `disabled` on an option disables
just that one. For more than a handful of choices, prefer `SelectField` or
`ComboBoxField`.
